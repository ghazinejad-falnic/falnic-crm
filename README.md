# Falnic CRM — افزونه مدیریت تریگرها و ارسال داده به CRM

افزونه وردپرسی برای ایجاد تریگرهای دیتابیس (Visual Triggers) و ارسال داده از هر جدول دیتابیس متصل به وردپرس به CRM فالنیک.

## ویژگی‌ها کلیدی
- نمایش، جستجو، فیلتر و صفحه‌بندی لیست تمام جداول دیتابیس وردپرس
- ایجاد تریگر روی رویدادهای INSERT / UPDATE / DELETE هر جدولی (پیش‌فرض وردپرس، دستی یا افزونه‌ای)
- رابطおいرة visuall با Drag and Drop برای نگاشت فیلدهای جدول منبع به پارامترهای لید CRM
- مقدار ثابت یا پویا (بر اساس ستون جدول) برای هر پارامتر با مقدار پیشفرض
- پیکربندی اتصال: Endpoint URL، X-API-KEY (رمزگذاری شده)، هدرهای سفارشی
- تست اتصال به CRM قبل از ذخیره
- ایجاد خودکار تریگرهای MySQL و مدیریت خطاها
- صف رویدادها (Cron Job) و ارسال asynchronous با cURL به endpoint CRM
- داشبورد آمار: تریگرهای فعال/غیرفعال، رویدادهای در انتظار/موفق/ناموفق، نمودار روند
- هشدار و اعلان از طریق ایمیل و پیامک (درایور پیامک قابل توسعه)
- لاگ فعالیت، کنترل دسترسی (manage_options)، رمزگذاری اطلاعات حساس، جلوگیری از SQL Injection
- هوک‌ها و فیلترها برای افزودن درایورهای CRM جدید

## نصب
1. پوشه `falnic-crm` را در `wp-content/plugins/` کپی کنید.
2. افزونه را از پنل وردپرس فعال کنید — جدول‌های مورد نیاز خودکار ساخته می‌شوند.
3. به منوی **فالنیک CRM > تنظیمات** بروید و آدرس endpoint، کلید API و هدرها را وارد کنید.
4. یک تریگر جدید بسازید، جدول منبع و Feldها را انتخاب کرده و نگاشت را انجام دهید.
5. تریگر را فعال کنید؛ رویدادها از طریق Cron یک‌در دقیقه پردازش و به CRM ارسال می‌شوند.

## نکات امنیتی
- کلید API در پایگاه داده رمزگذاری شده (AES-256-CBC).
- فقط کاربران با دسترسی `manage_options` می‌توانند به صفحات افزونه دسترسی داشته باشند.
- تمام نام‌های جدول و ستون در هنگام ایجاد تریگر در مقابل پایگاه داده تأیید (whitelist) می‌شوند تا SQL Injection inconceivable شود.
